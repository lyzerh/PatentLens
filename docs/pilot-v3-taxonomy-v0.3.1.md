# PatentLens 智能终端技术分类规范 v0.3.1

本规范供 10 篇探索性样本的人工 Gold 审核和 A/B/C/D 对照使用。版本与代码中的 `terminal-tech-v0.3.1` 一致。分类对象是**公开文献的主要技术贡献**，不是申请人的行业、产品上市事实、法律状态或专利价值。CPC/IPC 只能辅助判断技术方向，不直接生成企业产品线 Gold。

| 主技术标签 | 纳入（正例） | 排除与边界（反例） |
|---|---|---|
| Battery Management | 电芯状态、充放电控制、BMS 与电池安全控制 | 单纯外壳或液冷结构优先看结构/热管理；充电器与无线功率传输另列 |
| Wireless Charging | 感应/谐振功率传输、无线充电线圈及控制 | RFID/NFC 的感应通信不等于充电；有线充电连接器不属本类 |
| Thermal Management | 散热、冷却、热交换与温度调节是权利要求核心 | 仅提到温度作为状态输入，但创新点是电池控制，应归电池管理 |
| Display Technology | 像素驱动、发光器件、显示光学与成像呈现 | 单纯通信信号或电源控制不因出现在屏幕设备中而归显示 |
| Communication Technology | 无线/有线数据传输、调制、协议、天线或射频识别的信息功能 | 无线充电的功率传输不是通信；仅使用网络传输但创新点在电池/显示则归相应技术 |
| Device Structure | 外壳、支架、封装、机械连接与空间布置是核心贡献 | 仅作为技术实现载体的框架不自动成为主类 |
| Other | 原文足以判断主要贡献，但不落入以上有限标签 | 不能因来源缺失而用 Other；来源不足用 Unknown |
| Unknown | 原文不足、规则无法唯一判断或跨领域贡献尚未消歧 | 不等于“没有技术价值”，需人工复核 |

主标签按独立权利要求的技术贡献优先；权利要求缺失时结合完整摘要与标题，明确记下较弱证据。跨领域文献若一个贡献为核心，另一个为实施条件，则核心作主标签、另一个在 `technical_subdomain` 或审核备注说明；若两个贡献同等重要而当前单标签评估无法公平表达，标记 `ambiguous_or_uncertain=true`，不强迫给出虚假精度。当前 A/B/C/D 的准确率只评价主标签，不把开放文本当作完全字符串匹配。未来如启用多标签，应另建版本并使用多标签指标，不能与本版混报。

潜在产品场景单独从 `Smartphone`、`Earbuds / Headphones`、`Charging Accessories`、`Wearables`、`Other`、`Unknown` 中选择；它是可能用途，不是实际产品应用。若专利只涉及车辆、电网等且未见智能终端用途，选 `Other` 或 `Unknown` 并说明。`verified_product_implementation` 仅在有独立公开产品证据时才可判断；本轮数据字段固定为 `unknown`，不得从申请人、CPC 或模型猜测商业实施。

候选标签由官方 CPC/IPC 和固定关键词规则生成，附冻结原文中的精确片段，仅为 `provisional` 或 `needs_review`。人工复核应查看来源冲突、出版版本和缺失字段，并独立确认业务语义；未确认的候选不得计入 Gold 准确率。证据片段的字面出现不等于结论在语义上成立。
