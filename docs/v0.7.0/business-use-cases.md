# PatentLens v0.7.0 · Enterprise use cases / 企业应用场景

状态：设计草案，`enterprise-thermal-taxonomy-v2-draft`。本目录是研究规范，不改变 v0.6.0 运行行为。目标用户为智能终端制造商、消费电子企业、散热部件供应商的知识产权与技术情报团队。

## 研究对象与交付

专题为 Smart Device Thermal Management：手机、平板、笔记本、可穿戴设备及有明确归属的组成部分。分析单位首先是**指定版本的公开号**；同族、法律状态与商业产品另建实体，不从数量推断。

| 企业问题 | v0.6.0 已有基础 | v2 人工工作产物 | 不能据此声称 |
|---|---|---|---|

## 企业工作流

1. 固定检索式、检索日期、来源和公开号版本；记录未取回与重复项。
2. 检查 Claim 1、说明书实施方式与元数据完整性；缺失则升级复核。
3. 独立判定行业关联性，随后标注三维技术与产品语境；每项绑定原文及人工支持判断。
4. 按可追溯规则形成研究组合；用相同口径比较企业、技术路线与年份，并显示未知数。
5. 第二人处理边界和分歧；只有满足 Gold 协议的记录才进入正式模型评估。

一个包含 “phone” 的背景段落不能证明 Claim 1 限定手机，更不能证明实际产品采用。专利件数不能直接等同技术实力、商业价值、实施或侵权风险。

## 现阶段界限

公开仓库不分发 23 篇原文和三次付费响应。23 篇 EP 小样本不是总体抽样，verified Gold 为 0。现有申请人统计没有企业实体归一化；当前没有同族归并、法律状态复核、产品实施证据或实际人工耗时数据。正式竞争情报需要扩展检索覆盖、家族与申请人实体、时间版本及人工抽样核验。

**OPEN_DECISION B1**：企业首个正式试点的终端边界是否包含耳机、充电配件和独立散热附件？在决定前，分别记录具体产品，不合并进核心组合。

**OPEN_DECISION B2**：趋势分析的主时间轴采用优先权日、申请日还是公开日？必须在报告发布前锁定，不能混合计数。
