# PatentLens：能力与限制

PatentLens 是本机运行的企业专利研究**原型**，不是生产级资产管理或法律意见系统。 [返回图文用户指南](README.md)。

## 已实现

- 专利文件导入、登记、去重、公开号快速检索，以及允许字段的人工元数据更正与履历。
- 人工技术标签；无机器特征记录时，也可记录双专利差异、双方逐字引文和研究备注。
- 研究集合的保存、恢复及 Markdown／JSON 导出。
- 可选免费 Rules 技术特征提取，以及经过预检、费用确认和服务端授权的 xAI Grok 候选提取。
- 机器特征的结构、证据来源检查；中英文界面。

## 未验证或暂不支持

- 正式多人登录、身份核实、角色权限与完整审计治理。界面中的修改人是自填标识。
- 完整专利法律状态管理、全球范围检索覆盖或权属资产台账。
- 自动侵权／FTO 判断、技术等同结论、商业价值评估。引文精确匹配不证明语义判断正确。
- 生产环境的可靠性、安全审计、备份恢复和企业客户实际使用成效。

图文指南中的 EP9000001A1 等均为 **Synthetic／合成演示数据**，其编号与链接不代表真实 EPO 文献。
