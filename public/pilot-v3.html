01 / DATASET

样本与来源

当前使用带父版本的新冻结集；每条保留来源、获取时间、字段缺失、冲突和 SHA-256。旧版输入从不原地替换。

02 / DATA QUALITY

数据准备度

覆盖率按冻结样本计算，不写死百分比。缺失原因与跨公布版本冲突逐条列出；不同来源内容不由模型裁决。

03 / HUMAN GOLD

候选与人工基准

候选由官方分类与确定性规则产生，只供审核，不是 Gold。10 条均需独立人工确认；无法确认请选择 uncertain。商业实施始终 unknown。分类边界见 版本化分类规范。

04 / EXPERIMENT

四路对照

A 规则/CPC（无模型调用） → B 自由文本 → C JSON Schema → D 相同 C 输出加校验（无额外调用）。真实调用须先冻结 Gold，默认不重复收费。

05 / EVALUATION

Dashboard 与报告

未冻结 Gold 时准确率分母为 0；Mock 不计入真实评估。Schema 通过不等于语义正确，机械引文匹配不等于证据支持。
